# Портфолио: аналитика кредитного портфеля банка

**Роль:** самостоятельный демонстрационный проект по анализу данных и банковской отчётности.

**Задача:** разработать воспроизводимую модель портфеля из 100 000 кредитов, проследить динамику платежей и просрочек за три месяца и создать интерактивную панель управления.

**Технологии:** SQLite / SQL, Python, Excel, Plotly; подготовлены DAX-меры для Power BI. Нативный файл Power BI (.pbix) не создавался.

**Результаты (октябрь 2026):** остаток 439,58 млрд ₸; PAR30 16,63%; PAR90 3,10%; платежи за месяц 6,99 млрд ₸. Все цифры синтетические.

**Контроль качества:** 100 000 уникальных кредитов; 300 000 месячных записей; 0 отрицательных остатков/платежей; 0 некорректных DPD; 0 записей без соответствующего кредита; 0 дублей пары кредит-месяц.

**Что показывает проект:** построение базы данных, SQL-агрегации, расчёт KPI, динамику рисков, интерактивную фильтрацию по региону и продукту, оформление результатов для бизнеса.

**Ограничения:** данные сгенерированы алгоритмически; переходы DPD условные; не является финансовым прогнозом, скоринговой моделью или расчётом резервов по МСФО 9.
